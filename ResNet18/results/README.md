# Historical results (recovered from user's Kaggle console outputs)

These CSVs transcribe results from the previous training session. They are **not generated by a new execution of the reconstructed notebook**. No original model `.pth` and no original split CSVs are available in the uploads. We intentionally do not include a fabricated confusion matrix, missing inference speed, or test results for 8-view TTA. Test results for 4-view TTA were collected later as exploratory results, after the original test had already been viewed.
