# بداية سريعة للتسليم

1. فكّ الـZIP وارفع **محتويات مجلد** `Eye-Disease-Classification` إلى GitHub (مش الـZIP نفسه لو عايز الملفات تظهر للمدرّب مباشرة).
2. `README.md` فيه توثيق النتائج القديمة بصراحة؛ `notebooks/resnet18_full_reconstructed.ipynb` فيه كود مُعاد بناؤه، مش ملف التدريب الأصلي المفقود.
3. **ملف الموديل `.pth` غير موجود** في الملفات المسترجعة؛ علشان تعمل موديل قابل للتشغيل محتاج ترفع الداتا في Kaggle وتشغّل الـNotebook الجديدة. بعد التشغيل نزّل `eye_disease_training_outputs.zip` من `/kaggle/working` قبل إنهاء الجلسة.
4. **الجزء الأول (CNN من الصفر) غير مضمّن** لأنه لم يكن ضمن الشغل المسترجع. التسليم الكامل المطلوب في الـPDF يشترط النموذجين ومقارنة زمن التنبؤ.
5. أرقام الـTest التاريخية: Accuracy = 58.61% وMacro F1 = 49.65% من غير TTA. أعلى 8-view TTA على Validation = 63.60% Accuracy و52.68% Macro F1؛ ليس لدينا Test لـ8-view.
